# Workflows

[![Tests](https://github.com/Javaabu/workflows/actions/workflows/tests.yml/badge.svg?branch=main)](https://github.com/Javaabu/workflows/actions/workflows/tests.yml?query=branch%3Amain)
[![codecov](https://codecov.io/gh/Javaabu/workflows/branch/main/graph/badge.svg)](https://codecov.io/gh/Javaabu/workflows)
[![Latest Version on Packagist](https://img.shields.io/packagist/v/javaabu/workflows.svg)](https://packagist.org/packages/javaabu/workflows)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE.md)

Dynamic workflows for Laravel: versioned definitions with steps, transitions, assignees and conditions; instances with tasks, history and events; fluent definitions you can seed; a keyboard-accessible drag-and-drop builder; developer-defined actions; step data collected with [javaabu/form-builder](https://github.com/Javaabu/form-builder); a workflow tester and an optional AI assistant.

Under development: see [#17](https://github.com/Javaabu/workflows/issues/17).
